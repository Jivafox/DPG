# 本地开发、构建与导航

## 技术组成

主站为原生 HTML/CSS/JS，无前端框架、运行时 npm 依赖或服务端。Node 22+ 提供本地校验、构建、预览及测试。工具使用自己的独立文件，在同源 iframe 运行，主站不加载工具的 CSS/JS。

- `site/index.html`：首页、详情、找不到工具和加载状态的页面结构。
- `site/app.js`：读取 catalog、创建工具列表、导航和 iframe 生命周期。
- `site/styles/`、`site/assets/`：主站 token、样式与自有图形。
- `tools.json`：已纳入构建的工具顺序。
- `tools/<slug>/tool.json`：工具唯一元数据来源。
- `scripts/build.mjs`：校验、组装静态产物并校验输出。
- `scripts/serve.mjs`：仅监听本机、只提供 dist 的预览服务，不暴露源码与目录列表。

## 本地操作

```sh
npm test
npm run build
npm run preview
```

无需 npm install。构建默认读取本机仓库外词库；未配置时必须失败。浏览器打开终端显示的本地地址（默认端口 4174）。修改源码后重新构建并刷新；不会自动重载，构建失败不能继续将旧 dist 当成新结果。

仓库子路径验证另开一个终端：

```sh
npm run preview -- --port 4175 --base /DPG/
```

预览服务支持 GET/HEAD，仅提供 dist 内普通文件，不提供任意文件系统访问；它不是生产服务器。停止终端服务即停止预览。

## 导航契约

首页是站点根目录；详情使用 `?tool=<slug>`。列表点击用 History API 进入详情，浏览器前进/后退恢复相应页面，刷新详情从 URL 恢复选中的工具。URL 恢复的是页面，不是工具上传内容或参数。

“全部工具”和顶部 DPG 标识返回当前站点首页；“独立打开”在新窗口中打开工具的 index.html。Ctrl/Command 点击列表链接使用浏览器原生行为。无效 slug 显示站内错误及返回入口。

只有详情中选中的工具会被加载。离开详情移除 iframe、取消未完成加载；再次进入为新的工具会话。工具内的素材和参数不跨返回或刷新保存。工具的文件选择为本地处理，不是上传至站点服务器。

主站与工具地址均基于当前页面目录计算，支持域名根目录和任意仓库前缀，不写死域名根路径。列表失败可重试；工具地址先做 HEAD 检查，加载超时提供重试与独立打开。

## 构建边界

构建前检查源码和索引，将 site 复制到 dist 根，按索引顺序只复制 published 工具的运行文件，生成 catalog.json 和 .nojekyll。公开 catalog 只输出约定元数据字段，不复制 tool.json 的任意扩展字段。

draft/review/ready 工具、docs、scripts、Git 历史和词库不进入产物。工具目录只能包含运行资源和必要 LICENSE/NOTICE；不支持的类型、隐藏文件及符号链接会阻断构建，先评估再扩展允许列表。独立文档与验收记录放 docs。构建清理旧 dist，保证下架工具不遗留。

构建完成后自动用相同检查模式扫描 dist；也可运行 `node scripts/verify.mjs --dist --history`。私有检查覆盖源码、产物与可达历史的文本/字节匹配，图片可见内容和功能仍需人工检查。

## 测试

`npm test` 使用 Node 内置测试工具和临时 Git 仓库，验证构建白名单、未发布工具隔离、目录索引一致性、旧产物清理、符号链接阻断，以及发布标签/主线/版本记录门禁。

`npm run test:browser` 是可选的浏览器集成检查，不是生产依赖。需要本机已安装 Playwright 及可用 Chromium，先启动上述两个预览服务。若使用外部工具运行时，可在本地环境指定 `DPG_PLAYWRIGHT_MODULE` 与 `DPG_BROWSER_PATH`；不要将机器绝对路径写入仓库。可用 `DPG_QA_URL` 与 `DPG_QA_SUBPATH_URL` 覆盖预览地址（以斜杠结尾）。当前测试以首个 ASCII 工具为验收对象；更换首批工具时同步修改场景。

浏览器检查覆盖首页、进入/返回、刷新、历史导航、独立打开、iframe 上传/下载、失败重试与三档屏宽，截图放系统临时区。公开 CI 运行通用结构检查、Node 测试和结构模式构建；私有内容检查仍在本地执行，不能由 CI 绿色代替。
