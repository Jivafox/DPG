# DPG 发布 QA

## 每次改动

- [ ] 阅读规则，确认工作范围与已有文件；有 Git 时检查 status、分支、远端和 diff。
- [ ] 日常编辑可运行 `node scripts/verify.mjs --structure-only`；提交前必须配置仓库外私有规则并运行 `node scripts/verify.mjs`，两种结果分别记录；有 Git 时 `git diff --check` 和暂存区检查通过。
- [ ] 文案、路径、源码、图片、外链、素材许可与依赖完成人工复核。
- [ ] 不含密钥、内部链接、个人数据、无关追踪；必要许可声明未被删除。
- [ ] 规范、元数据、检查脚本及实际行为一致；未实现功能未写成已完成。

## 工具新增或更新（有工具时）

- [ ] 已自主识别入口、依赖和核心操作，私有整理记录区分已验证与待确认；未要求用户预先格式化材料。
- [ ] 保留原件，仓库外工作副本完成清理；独立工具目录、入口和元数据齐全。
- [ ] 主操作、重置、异常输入、键盘、触屏与减少动效设置有效。
- [ ] 390、768、1280px 布局和控件状态已实际检查。
- [ ] 本地 HTTP、iframe、独立打开和 Pages 子路径有效，无关键控制台错误或资源 404。
- [ ] 工具版本及日期同步，published 与索引一致，未发布工具不进入 dist。

## 主站与构建（实现后）

- [ ] 首页直接展开所有已发布工具，顺序符合索引；空状态可理解。
- [ ] 首版没有分类、搜索和筛选；无无效占位入口。
- [ ] 详情、返回、刷新、前进/后退、无效 slug 和独立打开正常。
- [ ] 首页不同时运行工具，详情只运行选中的工具。
- [ ] dist/index.html 存在，产物只含公开站点文件，仓库子路径资源正常。

## 每次外部写入前

- [ ] 规则文件在仓库外，真实词库、编码、指纹、命中原文和敏感路径未进入公开文件或日志；词库完整性已人工确认。
- [ ] 按 GitHub 工作流完成风险检查，包括本次公开内容与可达 Git 历史。
- [ ] 已展示精确 commit、远端、分支或标签、验证结果、自动化影响及回退方式。
- [ ] 已获得用户对本次 push 的明确确认；内容或目标变化后已重新确认。
- [ ] PR 创建、合并、版本标签/Release 与部署均在明确授权范围内；没有将分支 push 许可当作上线许可。

## 稳定版本与上线

- [ ] 通过功能分支及 PR 保留变更历史，CI 通过，不直接开发或推送 main。
- [ ] 版本标签唯一且不移动，发布记录包含变更、检查、风险和回退对象；Release 关联实际 commit 和结果。
- [ ] 规范版本不触发站点部署；站点仅部署已批准标签对应的版本。
- [ ] 站点部署成功并实测公开网址；失败如实记录，未把推送成功当作上线成功。

无 Git、无工具或无主站时，将对应条目标记为“不适用”并说明原因，不伪造通过；在首次接入或实现对应能力时补齐检查。
