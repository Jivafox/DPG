# ASCII Studio 2.0 与 Wax Seal 接入审核

日期：2026-09-29。范围：本地开发与预览，尚未推送或部署。

## 接收与公开边界

用户确认两个项目代码及必要素材可公开，并要求 ASCII Studio 1.0 与 2.0 独立展示。原件保留于仓库外；在仓库外工作副本审核、清理后，仅导入运行代码。未导入品牌图形、参考图片、参考视频、压缩包及系统缓存。封面由各工具自己的运行画布生成。

ASCII Studio 2.0 使用程序生成的动态渐变作为字符采样源，不替代原有图片/视频转换器。Wax Seal 是持续按压成型的火漆印章交互，不是图片油印滤镜；原版不提供下载，本次保留原有交互范围。

## 内容、依赖与修正

- 移除原身份标记与网络字体，使用系统及本机字体。未发现运行时外部 API、跟踪脚本或账号依赖；浏览器检查无外部请求。
- 渐变着色器与 React Bits Grainient 的实现对应，保留 `tools/ascii-motion/assets/NOTICE.txt` 中的版权和 MIT + Commons Clause 声明。该条款适用于作为应用一部分使用的着色器，不应把组件本身重新打包分发或出售。
- SVG 导入采用允许的元素/属性清单，清理根元素事件、脚本、样式、嵌入图片和外链；限制单文件 2 MB，保留非零 viewBox，去重并提供方向按钮排序。
- 工具外围统一 DPG 深色表面、文字、间距、蓝色强调与焦点。保持渐变配色、印章色彩和材质效果。小屏优先展示画布；减少动效偏好下 ASCII 默认暂停。

## 实际验证

Chrome 153，本地 HTTP 与 `/DPG/` 项目子路径：

- 三个首页入口、封面、站内 iframe、详情刷新、独立打开、返回与浏览器前进后退通过；原 ASCII Studio 的导入导出和错误恢复回归通过。
- ASCII 2.0：文字、背景、SVG 正常/异常输入、去重、排序、恶意 SVG 清理、尺寸设定、重置、PNG 导出通过。320 × 256、5 秒 MP4 实际导出后在浏览器解码，尺寸和时长一致；无 WebGL 时可显示降级渐变。
- 火漆：空文本、键盘按压、暂停/继续、完成、重置、非法 HEX 提示、合法色值和颗粒开关通过；模拟触摸长按/抬起正确暂停。
- 390 / 768 / 1280px 无横向溢出；新工具截图经过人工检查；减少动效模式检查通过。
- 页面脚本错误、资源错误、外部请求均为零。完整源码、产物及历史私有内容检查通过；Node 11 项测试通过。

复测命令：`npm run test:browser` 与 `npm run test:tools`。使用外部 Playwright 环境，通过 `DPG_PLAYWRIGHT_MODULE`、`DPG_BROWSER_PATH` 指定依赖与浏览器，`DPG_QA_URL`、`DPG_QA_SUBPATH_URL` 指定运行中的预览地址。工具检查默认子路径预览端口为 4181。MP4 解码和无 WebGL 验证为本次单独执行的审核项。

## 限制

尚未部署本版；Safari、Firefox、真实手机和大尺寸/10 秒视频未全面验证。WebGL 不可用时渐变为简化效果；视频编码依赖浏览器能力。返回首页或刷新会重置工具内状态。两款工具均独立保存本地资源，不跨工具导入 CSS/JS。
