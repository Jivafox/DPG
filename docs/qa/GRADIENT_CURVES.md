# Gradient 2.0（gradient-curves）接入审核

日期：2026-09-29。范围：本地开发与预览，尚未推送或部署。

## 接收与公开边界

用户提供 React + TypeScript + Vite 原件（仓库外 `toolbox/gradient2.0/`，自称 Colir），确认可公开。按仓库"无前端框架、原生 HTML/CSS/JS"约定，未直接导入源码或构建产物，而是将核心逻辑移植为原生工具 `tools/gradient-curves/`（index.html 142 行 + styles.css 128 行 + app.js 1700+ 行），未导入脚手架、截图素材与任何 npm 依赖。封面由工具自己的运行画布生成（关闭曲线覆盖层后截取，裁为 4:3）。

## 内容、依赖与修正

- 移除全部 "Colir" 品牌痕迹（标题、logo、CSS 类前缀、导出文件名、注释），grep 验证为零；统一为 Gradient 2.0 / DPG / 05 中性身份；UI 全部翻译为中文。
- 引擎（engine/state/colors/noise/blend）近乎逐行移植，无第三方代码；图标为内联 SVG（lucide 风格，MIT）。零网络请求、零外部字体、零 localStorage。
- 修复两处原作问题：① 大导出（>200 万像素分带渲染）丢失 glitter/pattern 覆盖层，拼带后补合成；② 剪贴板被拒时回退为阻塞式 `window.prompt`（嵌进 iframe 会卡死页面），改为 execCommand 后备 + 行内展示链接手动复制。
- 布局与 ASCII Studio 标准一致：左侧 100vh 固定参数面板（独立滚动）、右侧开放舞台（#000 + 52px 工具条 + 尺寸 meta）、移动端舞台吸顶；外围控件全部 DPG token。

## 实际验证

桌面浏览器，本地 HTTP 预览：

- 初始渲染、12 个模板弹窗实时缩略图与应用（Aurora）、画布控制点拖拽实时重塑、随机全部、X/Y 切换、曲线显示开关通过。

- 分享链接：点击无阻塞、反馈正常；剪贴板被拒场景已改为非阻塞后备（代码走查 + 面板环境实测不再卡死）。
- 390px：舞台吸顶在上、面板在下，无横向溢出；页面无脚本错误、无外部请求。
