## 范围与状态

首个工具以 `ascii-studio` 接入，版本 1.0.0，状态 published，已进入 tools.json 和本地构建产物。published 表示通过当前本地 QA 并具备构建资格，不表示已部署。主站和构建已实现，Pages workflow 已准备但尚未在线配置或触发。

用户已确认工具代码为本人创作并允许公开。原始文件保留在项目外，仅导入经过清理的 HTML、CSS、JS；原有品牌图形、附带图形集合、系统元数据未导入。未引入运行时第三方代码或分发字体文件；字体选择使用本机字体，不存在时由浏览器回退。项目整体开源许可仍需在公开前另行确定。

## 核心体验与变化

保留图片/视频转字符画、文字或自定义 SVG 字符、颜色与渐变、画布比例及明暗/间距等参数、PNG 1x/2x/4x、SVG 和无声视频导出。导出视频优先使用浏览器离线 MP4 编码，不支持时尝试实时录制，格式依浏览器能力而定。

- 替换旧身份，取消外部字体请求；控件按 DPG 深色 token 统一，手机优先显示预览。
- 修复 SVG 上传重复添加，以及重复项缺少 viewBox 导致导出失败；导出补偿非零 viewBox 原点。
- SVG 字符限于基础静态矢量元素与属性，去除脚本、事件、嵌入文档和外部资源；文件名进行 HTML 转义。复杂滤镜、动画或外链 SVG 可能不被保留。
- 视频定位增加当前帧判断和超时，避免从零时刻导出等待不触发的 seek 事件；处理编码器异步错误并关闭编码器。
- 导出期间禁用会影响结果的控件；补齐空状态、无素材时导出禁用、损坏图片提示、键盘焦点与减少动效。
