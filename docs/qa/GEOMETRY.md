# Geometry 接入审核

日期：2026-09-29。范围：本地开发与预览，尚未推送或部署。

## 接收与公开边界

用户提供单文件 HTML 原件（几何生成器 · Geometric Constructor），确认可公开。原件保留于仓库外会话附件区；审核清理后拆分为 `index.html` / `styles.css` / `app.js` 导入，未导入其他素材。封面由工具自身导出功能生成（黄金圆阵 2x PNG 裁为 4:3）。

## 内容、依赖与修正

- 原件无品牌/人名/公司/链接/追踪；无外部请求、无外部字体、无 localStorage。`innerHTML` 仅用于注入静态中文字符串，无注入面。
- 清理指向不存在"参考图"与外部风格出处的注释，改为独立技术描述；导出文件名由中文改为 `geometry-{mode}-{seed}[-{n}x].{png,svg}`；按钮去表情符号改文字标签。
- 身份统一为 Geometry / DPG / 06；布局统一 ASCII Studio 标准（左侧 100vh 固定面板、右侧开放舞台 + 52px 工具条 + 尺寸 meta、移动端舞台吸顶）；操作区置顶、模式切换与动态参数区收进面板；控件全部 DPG token。
- 功能零删减：7 种构图模式、按模式定制量程的参数面板、种子复现、画幅比例、黑/白底反色、对称、PNG（1–4x）与 SVG 矢量导出、`?mode=` 链接参数。

## 实际验证

桌面浏览器，本地 HTTP 预览：

- 初始渲染、模式切换（随机混合/黄金圆阵/相切圆链等）、动态参数面板随模式重建、滑杆实时渲染通过。
- 导出实测：2x PNG（3600×3600）与 SVG 均完成；SVG 内容校验有效（背景矩形 + 70 条路径 + 6 条文字标注，1800×1800 viewBox）。
- 390px：舞台吸顶在上、面板在下，无横向溢出；页面无脚本错误、无外部请求。
