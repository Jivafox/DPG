# Gradient 与 Wax Seal 布局统一审核

日期：2026-09-29。范围：本地开发与预览，尚未推送或部署。

## 范围与边界

应用户要求，以 ASCII Studio 的布局为唯一标准，仅调整 Gradient 与 Wax Seal 两个工具的布局，不修改任何功能逻辑。

目标结构（与 ASCII Studio 一致）：左侧固定参数面板（100vh、独立滚动、右边线分隔），右侧开放预览区（黑色画布底、52px 工具条、内容不再套独立边框窗口）；面板顶部放置紧凑标识块（DPG 编号 + 名称 + 一行简介）；移动端预览区吸顶在上、面板在下整页滚动。

## Gradient

- 面板由右侧移至左侧；预览区移除圆角面板窗口，改为开放舞台 + 工具条；工具条右侧显示当前画布尺寸（随预设切换更新，纯展示）。
- 标识块（DPG / 04 + Gradient + 简介）保留在面板顶部；无独立页眉与页面标题区。

## Wax Seal（v1.0.0 → v1.0.1）

- 移除独立页眉（DPG / 03 · 交互实验）、页面大标题区与底部步骤条；标识块与三步说明移入左侧面板。
- 印章内容输入与材质控件全部收进左侧面板；右侧开放舞台中央放置印章画布（保留装饰圆环与按压交互），状态提示移至工具条右侧，压力条与"重新融蜡"按钮移至舞台底部条。
- 全部 JS 钩子（id/class/aria）保持不变，渲染与状态机未改动；`tool.json` 版本升至 1.0.1。

## 实际验证

桌面浏览器，本地 HTTP 预览：

- Gradient：1280px 下面板左置固定、独立滚动，预览区开放无嵌套窗口，工具条尺寸读数正确；390px 下预览吸顶、面板在下，无横向溢出。
- Wax Seal：1280px 布局与 ASCII Studio 同构；输入文字后计数、状态点与提示语、印章就绪态均正常；390px 下预览吸顶、控件完整。
- 控制台无脚本错误、无资源错误、无外部请求；完整私有内容检查与构建通过（dist 含 4 个 published 工具）。
