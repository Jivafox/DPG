# DPG 设计系统 · V1

## 视觉原则

深色、安静、内容优先。结构依靠对齐、间距、少量细线；导航低于内容层级。借鉴 Linear 的信息密度与交互秩序，使用 DPG 自有标识、颜色与文案，避免复制其商标、图标和页面。

## 基础 token（建议落地为 `site/styles/tokens.css`，工具可拷贝值而非跨目录 import）

| 用途 | token | V1 值 |
| --- | --- | --- |
| 画布 | `--bg-canvas` | `#0b0c0f` |
| 一级表面 | `--bg-surface` | `#111318` |
| 浮层 | `--bg-elevated` | `#191b21` |
| 悬停 | `--bg-hover` | `#202229` |
| 主文字 | `--text-primary` | `#f0f1f3` |
| 次文字 | `--text-secondary` | `#a0a3ad` |
| 弱文字 | `--text-muted` | `#777b86` |
| 细线 | `--border-subtle` | `#272a31` |
| 强调 | `--accent` | `#8b90ff` |
| 聚焦 | `--focus-ring` | `#aeb1ff` |

字族优先系统 sans（`Inter, ui-sans-serif, system-ui, sans-serif`）；正文 14px/1.5，辅助 12–13px，区块标题 18–24px，页面标题 28–36px。间距以 4px 为基础，常用 8/12/16/24/32；圆角控件 6px、面板 8px。边框一般 1px；不要靠大面积阴影制造层级。

## 首版页面结构

首页为顶部标识、简短说明与全部工具列表，不设分类侧栏、搜索框和筛选控件。详情页为标题与操作区、工具运行区；返回入口清晰可见。通用表单规范用于工具自身需要的控件，不扩大首版主站范围。

## 组件与状态

| 组件 | 默认规格 | 状态要求 |
| --- | --- | --- |
| 按钮 | 高 32px，水平内距 12px，圆角 6px | hover、focus-visible、disabled、loading |
| 输入（工具按需使用） | 高 36px，表面色，1px 细边 | 占位与输入对比清楚，错误可读 |
| 列表行 | 最小高 56px；标题、描述、辅助信息分层 | 整行可点击，键盘焦点可见 |
| 面板 | 1px 细边、8px 圆角 | 不叠过多容器 |
| 工具栏 | 控件间距 8px；次级操作弱化 | 窄屏换行或折叠 |

交互反馈一般 120–180ms ease-out；大区域切换 180–240ms。遵守 `prefers-reduced-motion`，避免用动效作为唯一信息。交互实验的画布可自由表达，但外围导航、参数区和通用控件沿用上述语言；不要为了统一损坏实验的核心效果。

## 响应式与无障碍

设计检查宽度至少 390 / 768 / 1280px；窄屏优先工具画布与主要动作，首页与详情保持单栏。保证键盘操作、可见焦点、语义标签；文本与控件对比度按 WCAG AA 目标评估。鼠标专属效果需给触屏合理替代。内容语言可按工具定位选择，但同一界面保持一致。

## 评审方法

先记录工具原始的核心体验，再标记可统一的导航、表单、面板和文字；用设计 token 重构外围，在三档宽度及交互状态下截图对照。若视觉规则与功能冲突，保留功能并在工具说明中记例外原因。
