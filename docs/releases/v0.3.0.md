# DPG v0.3.0

Version: v0.3.0
Release-Type: site

日期：2026-09-29

## 变更

新增四个工具并统一全站布局与命名：

- **Gradient I**（gradient）：随机和谐配色渐变纹理生成，调节团块/羽化/景深/颗粒，导出高分辨率 PNG。
- **Gradient II**（gradient-curves）：双贝塞尔曲线场渐变（自 Colir 移植为原生实现），12 个模板、Distortion/Glitter/Patterns、动画、1–4x PNG/WebP 导出与分享链接。
- **Geometry**：七种几何构图模式（网格/黄金圆阵/黄金螺旋/相切圆链/场线/投影几何），种子复现，PNG 与矢量 SVG 导出。
- **Sphere**：Three.js 符号球（自 Symbol Sphere 移植为原生实现），拖拽旋转 + 惯性、大陆分布调节、自定义符号上传；three.js 0.184.0 官方构建 vendor 并附 NOTICE.txt（MIT 保留）。
- 布局统一为 ASCII Studio 标准：左侧固定参数面板、右侧开放舞台、移动端舞台吸顶；Seal 移除印章装饰圆环；Gradient I/Geometry 的画幅与生成控件置顶。
- 工具改名：ASCII Studio → ASCII I（1.0.3）、ASCII Studio 2.0 → ASCII II（2.0.1）、Wax Seal → Seal（1.0.3）。

## 最新视觉与素材更新

- 主站与工具外围采用 V2 中性深色主题；主行动按钮为高亮白底深色字，键盘焦点为白色环。最新 token、控件规格与响应式规则见 `docs/DESIGN_SYSTEM.md`。
- 首页使用 Design Playground 标题与简介，内容容器最大宽度 1200px；工具网格按屏幕宽度展示三列、两列或一列。恢复工具标签，桌面行距 44px、列距 20px。
- 工具卡片取消外框、底色与投影，采用 4:3 圆角封面，名称、简介及标签置于封面下方；悬停时封面轻微放大。
- 更新 ASCII I、ASCII II、Seal、Gradient I、Gradient II、Geometry、Sphere 的全部七张封面，均为 640 × 480px，保留各自 `tools/<slug>/assets/cover.png` 固定替换位置。路径清单见 `docs/COVERS.md`。
- 更新 `site/assets/mark.svg` 为白色放射形标记与圆点，顶栏 Logo 和浏览器 favicon 共用该素材。
- 同步 README、仓库蓝图与接入默认约定；浏览器回归断言使用 ASCII I，首页目录按构建 catalog 校验工具数量与顺序。

上述七张封面与 Logo 随本版本纳入 Git，保留固定资源路径。发布前核对最终提交与构建产物一致；本记录不替代推送与上线确认。

本文件为本地发布准备，不代表已推送、合并或上线。准确提交、PR、标签及部署记录在获得确认后写入 GitHub Release。

## 限制与回退

Safari/Firefox/真实移动端尚未全面验证；Sphere 的真实文件上传路径未端到端点击验证；高倍导出与高密度场景在低端设备上可能较慢。若新版本回归，以 v0.2.0（fb3c44c23694a23cf5dcb9892447b7172ce58ffa）为恢复目标，通过新提交、PR 和新版本发布，不移动既有标签、不重写共享历史。
