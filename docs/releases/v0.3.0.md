# DPG v0.3.0

Version: v0.3.0
Release-Type: site

日期：2026-09-29

## 变更

新增四个工具并统一全站布局与命名：

- **Gradient I**（gradient）：随机和谐配色渐变纹理生成，调节团块/羽化/景深/颗粒，导出高分辨率 PNG。
- **Gradient II**（gradient-curves）：双贝塞尔曲线场渐变（自 Colir 移植为原生实现），12 个模板、Distortion/Glitter/Patterns、动画、1–4x PNG/WebP 导出与分享链接。
- **Geometry**：七种几何构图模式（网格/黄金圆阵/黄金螺旋/相切圆链/场线/投影几何），种子复现，PNG 与矢量 SVG 导出。
- **Sphere**：Three.js 符号球（自 Symbol Sphere 移植为原生实现），拖拽旋转 + 惯性、大陆分布调节、自定义符号上传；three.js 0.184.0 官方构建 vendor 并附 NOTICE.txt（MIT 保留）。
- 布局统一为 ASCII Studio 标准：左侧固定参数面板、右侧开放舞台、移动端舞台吸顶；Seal 移除印章装饰圆环；Gradient I/Geometry 的画幅与生成控件置顶。
- 工具改名：ASCII Studio → ASCII I（1.0.3）、ASCII Studio 2.0 → ASCII II（2.0.1）、Wax Seal → Seal（1.0.3）。

## 审核与验证

原始材料均在仓库外审核清理后导入或移植，移除原品牌身份（Botanical/Colir/Symbol Sphere）与失效引用；修复移植中发现的大导出丢覆盖层、剪贴板回退阻塞、降级提示常驻等问题。各工具浏览器走查记录见 `docs/qa/GRADIENT.md`、`GRADIENT_CURVES.md`、`GEOMETRY.md`、`SPHERE.md`、`LAYOUT_UNIFY.md`。本地完整私有检查（含 --history）、11 项 Node 测试、构建（dist 含 7 个 published 工具）通过。

本文件为本地发布准备，不代表已推送、合并或上线。准确提交、PR、标签及部署记录在获得确认后写入 GitHub Release。
