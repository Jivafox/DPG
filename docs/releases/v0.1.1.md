# DPG v0.1.1

Version: v0.1.1
Release-Type: site

日期：2026-09-28

## 变更与原因

v0.1.0 的 Pages 运行在版本检查阶段失败，未上线。发布 workflow 现在显式检出触发标签，保留附注标签对象；门禁继续检查附注标签、HEAD、main 历史和发布记录，并额外要求 Actions 的事件提交与标签指向相同，防止检出不同版本。站点页面和工具内容保持 v0.1.0 的审核范围。

## 验证与状态

本地测试覆盖事件提交一致、不一致和缺失时的行为；继续运行完整构建、私有源码/产物/历史检查。最终 CI、合并提交和部署运行记录在对应 GitHub Release 中记录。远端成功部署和公开网址验收前不视为上线。

## 风险与回退

站点沿用账号主页的自定义域名，HTTPS 证书和公开可达性仍需复查。尚无成功上线的稳定版本；v0.1.0 不能作为线上回退目标。若上线失败则保留现有标签，通过修复 PR 和新的版本发布；必要时经确认撤下 Pages，不移动旧标签或改写共享历史。
