# 版本记录模板（不代表已发布版本）

准备稳定版本时复制为 `docs/releases/<实际标签>.md`，填写具体内容并随功能分支通过 PR 合入。不要直接把模板作为发布记录。机器校验要求记录中独占一行的 `Version:` 与 `Release-Type:`，类型为 site 或 spec；占位符必须替换。

```text
Version: <实际版本标签>
Release-Type: <site 或 spec>
```

- 日期：
- 本版变更与关联 PR：
- 验证结果（本地私有检查、构建、浏览器检查）：
- 已知限制与风险：
- 回退目标（上一稳定标签或首次上线无上一版本）：
- 回退步骤：通过恢复提交、PR 和新版本发布，不移动旧标签。

实际合并 commit、标签和部署运行链接在 GitHub Release 中补记。只有获得对具体标签、commit 和部署影响的明确确认后才推送标签；本地记录不等于推送或上线许可。
