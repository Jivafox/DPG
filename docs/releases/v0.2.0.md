# DPG v0.2.0

Version: v0.2.0
Release-Type: site

日期：2026-09-29

## 变更

新增 ASCII Studio 2.0 动态渐变字符画与 Wax Seal 火漆交互；保留 ASCII Studio 1.0，首页平铺三个独立入口。统一深色控件及蓝色强调，各工具提供可直接替换的 `assets/cover.png`。

## 审核与验证

原始材料在仓库外审核清理；保留着色器必要第三方许可。修正 SVG 导入过滤、重复导入和非鼠标排序。工具、站内导航及已有工具回归记录见 `docs/qa/NEW_TOOLS.md`。

本文件为本地发布准备，不代表已推送、合并或上线。准确提交、PR、标签及部署记录在获得确认后写入 GitHub Release。

## 限制与回退

大尺寸/长视频及跨浏览器兼容性尚未全面验证；火漆保留原版体验，不含下载功能。若新版本回归，以 v0.1.1（571a281c219b5b675b05f8e03fe335f74d1526af）为恢复目标，通过新提交、PR 和新版本发布，不移动既有标签、不重写共享历史。
