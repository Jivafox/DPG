## 已知限制

- 返回首页或刷新会重置工具内的上传素材和参数。
- 长视频、大尺寸素材与各浏览器的视频编码兼容性尚未全面验证。
- 首次发布前没有既有线上版本；线上路径、资源、导航和下载需在部署后复查。

## 回退

这是首次站点版本，没有上一稳定网站可直接恢复。若首次上线出现阻断使用的问题，先停止后续发布，必要时经用户确认撤下 Pages；保留源码历史，通过修复分支、PR 和新的版本标签重新发布。已经发布的 v0.1.0 标签不移动，不强推 main。
